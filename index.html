About me

I'm a backend-focused software engineer who enjoys the parts of a system most people never see: how services exchange events, how data stays consistent across them, and how the whole thing behaves under load.

I work mostly with Java and Spring Boot, stream data through Apache Kafka and Apache Flink, capture database changes with Debezium, and run it all on Docker and Kubernetes with Prometheus watching. My final-year research looked at resizing Kubernetes workloads on the fly without breaking latency targets.

Right now I'm going deep on stream processing internals (Kafka Streams, consumer-group rebalancing, Flink state and checkpointing) and building interactive tools that teach them.
